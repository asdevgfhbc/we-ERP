# we-ERP Frontend

Modern ERP frontend built with React, TypeScript, Tailwind CSS, and reusable shadcn-style UI primitives.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- Recharts
- Sonner (toast notifications)

## Features

- Left collapsible sidebar and top navigation
- User profile dropdown and notifications panel
- Breadcrumb navigation
- Responsive layout for desktop, tablet, and mobile
- Dark and light mode support
- Full ERP module routing with mock data
- Reusable data table, filters, pagination, form sections, file upload area, loading skeletons, and empty states

## Run

1. Install dependencies:

   npm install

2. Start dev server:

   npm run dev

3. Build for production:

   npm run build
